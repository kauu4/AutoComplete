Fast Autocomplete System in C
Hey there! This project is a super-fast Autocomplete and Spell-Checker engine written in C. It uses a Trie (Prefix Tree) data structure to suggest words instantly as you type—just like the search bar on Google or your phone's keyboard.

✨ Features
⚡ Lightning Fast: Finds matching words in milliseconds, no matter how big the dictionary is.

🎯 Top 5 Suggestions: Keeps the terminal clean by showing only the 5 best matches instead of flooding your screen.

📈 Popularity Tracker: Remembers what you search for! Searching a word increases its search count so popular words show up first.

⏱️ Search Timer: Displays the exact execution time for every query down to fractions of a millisecond.

🧹 Smart Input Handling: Ignores messy capitalization or spaces so the search never crashes.
